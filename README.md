# aioman-skills

AIOMAN skills marketplace for Claude - Arabic RTL presentations skill.

## المهارات
| المهارة | الوصف |
|---|---|
| aioman-presentations | عروض PowerPoint عربية بهوية AIOMAN |

## التثبيت في Claude
1. Plugins ← Add ← Add marketplace
2. اكتب: `AIOMAN-OM/aioman-skills` ثم Sync
3. ثبّت aioman-presentations

## ChatGPT
ارفع مجلد المهارة مضغوطًا من Skills ← Upload.

## Gemini
انسخ الاسم والوصف والتعليمات من SKILL.md إلى صفحة إنشاء المهارة.
